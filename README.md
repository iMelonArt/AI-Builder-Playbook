## Introduction

AI Builder Playbook brings together research papers, practical AI proof-of-concept projects and data engineering resources for learning, experimenting and building AI applications. Created by Melony Qin (cloudmelon) at iMelonArt, it combines the original AI Playbook, AI CodePlaybook and Data Playbook collections in one repository.

Explore local AI and retrieval-augmented generation (RAG), cloud-based AI experiments, and the data foundations behind AI products. Start with the introduction video, then follow the [AI startup YouTube playlist](https://bit.ly/ai-startup-cloudmelon) for the series.

[![Watch the AI startup project introduction](https://img.youtube.com/vi/0FoRYTFwGec/0.jpg)](https://www.youtube.com/watch?v=0FoRYTFwGec)

## Project details

| Folder | Contents |
| --- | --- |
| [Resources](Resources/README.md) | The original **AI Playbook** collection: AI/ML research papers, technical reports and learning references. Its bundled papers are in [Resources/Resources](Resources/Resources/). |
| [POVs](POVs/README.md) | The original **AI CodePlaybook** collection: hands-on AI experiments, proof-of-concept implementations and setup instructions, including [MelonRagGPT](POVs/melonRagGPT/), [MelonRagGPTLite](POVs/melonRagGPTLite/), [Azure OpenAI experiments](POVs/melonOpenAIRagGPT/) and [AI basics](POVs/ai-101/). |
| [Data](Data/README.md) | The original **Data Playbook** collection: data analytics concepts, architecture notes, business continuity and disaster recovery, demos and reference material. |

Each collection retains its own README, source files and license. Follow the setup instructions for the specific example you want to run.

For a walkthrough of setting up local AI with containers, see [How I built an LLM-based local AI for free in containers](https://cvisiona.com/how-i-built-an-llm-based-local-ai-for-free-in-docker-containers/).
