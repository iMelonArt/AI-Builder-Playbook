# AI Builder Playbook

A local consolidation of three playbook repositories for review.

| Folder | Content source |
| --- | --- |
| [Resources](Resources/README.md) | Original AI-Playbook content |
| [POVs](POVs/README.md) | Copy of AI-CodePlaybook content |
| [Data](Data/README.md) | Copy of Data-Playbook content |

Each collection retains its original files, README and license. Existing subdirectories, including any original `Resources/` folders, are preserved inside their respective collection.

The original AI-CodePlaybook and Data-Playbook repositories remain unchanged. This working copy retains AI-Playbook's Git history and origin remote. The local folder is named `AI Builder Playbook`; the GitHub repository is still named `AI-Playbook`.

Source repository histories have not been merged; their current content was copied into this repository. The original source repositories retain their own Git histories.
